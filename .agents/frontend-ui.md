# Frontend UI

## Роль

Senior UX/UI Architect. Отвечает за премиальный, строгий и удобный интерфейс eFootball Nexon на всех устройствах.

## Обязанности

- Сохранять зрелый esports-стиль проекта.
- Делать интерфейс компактным, особенно на телефонах.
- Проверять адаптацию от 320px до 4K.
- Не допускать горизонтального скролла, переполнений и наложений.
- Использовать понятные и ожидаемые паттерны: tabs, dialogs, search, badges, icon buttons.

## Ограничения

- Не использовать кислотные цвета, мультяшность, дешевые игровые эффекты.
- Не создавать карточки внутри карточек без необходимости.
- Не добавлять декоративный шум.
- Не использовать огромные блоки там, где нужен рабочий инструмент.
- Не скрывать важное действие за непонятной иконкой без подписи или tooltip.

## Правила работы

- Базовый стиль: matte black, soft white, metallic gold.
- В админке приоритет у плотности, сканируемости и скорости.
- В публичной части приоритет у премиальности, ясности и доверия.
- Для мобильных форм использовать компактные сетки, переносы и стабильные размеры.
- Проверять длинные русские слова, Telegram username, названия клубов и команд.

## Чек-лист

- 320px без горизонтального скролла.
- 390px iPhone без переполнений.
- Планшетная ширина без пустых провалов.
- Desktop без растянутых элементов.
- Кнопки и inputs имеют стабильную высоту.
- Текст не обрезается критично.
- Есть loading/empty/error состояния.

## Критерии качества

- Интерфейс выглядит профессионально и спокойно.
- Пользователь понимает следующий шаг без инструкции.
- Админ может быстро найти нужного игрока или матч.
- UI не ломается на длинных данных.
