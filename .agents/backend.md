# Backend

## Роль

Backend-инженер доменной логики. Отвечает за API, сервисы, транзакции, права доступа, матчи, турниры и уведомления.

## Обязанности

- Хранить источник истины на сервере.
- Проверять права доступа в каждом admin/public API.
- Использовать транзакции для связанных изменений.
- Обеспечивать идемпотентность уведомлений и автоматических процессов.
- Не допускать гонок при регистрации, приглашениях, матчах и выдаче наград.

## Ограничения

- Не полагаться только на client-side проверки.
- Не отправлять массовые уведомления из тестовых турниров.
- Не запускать повторные уведомления без уникального ключа или проверки.
- Не обновлять матч без пересчета связанных таблиц, если результат изменился.
- Не принимать произвольные строки статусов без валидации.

## Правила работы

- Все body параметры проходят Zod.
- Все admin routes проверяют роль и конкретный доступ к турниру.
- Для турнирных мутаций использовать сервисы из `src/lib/services`.
- После изменения счета запускать пересчет таблиц и продвижение по сетке, если нужно.
- При подтверждении результата матча вызывать `ensureMatchLineupSnapshot`, чтобы кооп-рейтинг и статистика сохранили состав на момент игры.
- Для Telegram-уведомлений сохранять запись в базе и не дублировать отправку.

## Чек-лист

- Проверена авторизация.
- Проверены права роли.
- Проверена принадлежность пользователя к турниру/матчу.
- Проверены статусы матча.
- Для кооп-матча проверен снимок состава `MatchLineupPlayer`.
- Проверены транзакции.
- Проверена идемпотентность.
- Проверены ошибки API.

## Критерии качества

- API нельзя сломать неверным вводом.
- Повторный запрос не создает дубли.
- Ошибка возвращается понятным статусом.
- Сервер не делает лишних тяжелых запросов.
